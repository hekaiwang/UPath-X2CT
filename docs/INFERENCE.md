# Inference contract

The released model is one file, `upath_x2ct_final.pt`. It contains the
normalized autoencoder, coarse conditioning network, residual diffusion,
training-only projection normalization, CT-to-HU scale/offset, and projector
calibration. EMA values are materialized as ordinary state dictionaries;
autoencoder latent statistics and diffusion residual scales remain in their
model buffers. No optimizer, training examples or ground-truth volumes are packaged.

The selected diffusion checkpoint is step 22,000, paired with the original
frozen autoencoder and step-20,000 coarse component. These are internal components
of one final model; there is no separately released coarse checkpoint or standalone
coarse result table in the current release. `configs/weights.json` records the
final-file checksum and source provenance. The predictor accepts the `.pt` path
or a directory containing it and loads it directly without extracting component files.

## Projection inputs

An NPZ or HDF5 needs exactly these input arrays:

| Key | Shape | Meaning |
|---|---|---|
| `drr_frontal_ap` | 512×512 | Raw AP line-integral DRR, before log1p standardization |
| `drr_left_lateral` | 512×512 | Raw left lateral DRR |
| `projection_matrices` | 2×3×4 | AP/LAT homogeneous camera matrices in centered physical LPS coordinates |

An HDF5 generated by `prepare_data.py` can be passed directly. The predictor
opens only these three arrays. For independent projection acquisitions, supply
calibration consistent with the same 384-mm field of view, centering, detector
axes and intensity convention. A PNG/JPEG of an arbitrary radiograph is not a
calibrated input for this model.

The network grid is ZYX, with voxel-center origin (-190.5,-190.5,-190.5) mm in
centered LPS and 3-mm isotropic spacing. The output NIfTI is XYZ in RAS:
diagonal affine (-3,-3,3,1), translation (190.5,190.5,-190.5). It does not include
the source patient's thorax-center translation. Add that known translation
when mapping back into original patient coordinates.

## Sampling

The default is K=8, 50 DDIM steps, eta=0, seed 20260724. Each sample's seed is a
SHA256 function of the base seed, case ID and sample index. Use the published
case ID when replaying a study case. Mean and population standard deviation
are computed after decoding and clipping each sample. Standard deviation is
reported in HU and is not a calibrated clinical confidence interval.

Published aggregate metrics use the historical predictions. See
`reproducibility/inference_validation.json` for measured replay differences and
the scope of the release check; BF16 output is not promised bitwise identical
across hardware/software stacks.

The Hub provides the single final checkpoint. The download script fetches the
pinned revision and verifies its SHA256 before use. Combining the components
changes their storage layout only; it does not alter precision or resolve
historical replay differences. See `reproducibility/final_bundle_validation.json`
for the comparison against the previous three-file inference layout.
